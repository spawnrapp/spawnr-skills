# Spawnr protocol

This folder holds [PROTOCOL.md](PROTOCOL.md), the rules the `spawnr`, `spawnr-mcp` and `openclaw` skills share. Those skills link to it as `../spawnr-protocol/PROTOCOL.md`, so it is installed as a skill folder beside them. It adds no commands and no rules of its own: read [PROTOCOL.md](PROTOCOL.md) when one of those skills sends you here.
